# AllHealth 🏥

AllHealth is a full-stack patient management system that gives patients a modern, 
digital way to book appointments, receive notifications, and manage their 
healthcare, something that currently doesn't exist in the Irish public health system.

The project was originally developed during 3rd Year as an industry-partnered 
placement project, and continued through final year as my final year project 
at the Technological University of the Shannon.

---

## 📱 Platforms

- **Android App** — Built in Java using Android Studio
- **Web Platform** — Built with HTML, CSS, and JavaScript

Both platforms connect to the same Firebase backend, allowing real-time 
synchronisation across all devices.

---

## 🔑 Key Features

- Patient appointment booking and management
- Real-time notifications and schedule updates
- Firebase authentication for secure login
- Works independently, no localhost required, multiple users supported simultaneously
- Unified backend shared between the app and website
